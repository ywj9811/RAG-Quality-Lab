# 06. 화면 구성 및 와이어프레임 (텍스트)

- 하나의 React 앱, 라우트로 역할 분리: `/` (방문자 채팅), `/admin/*` (관리자).
- 모든 문구는 한국어. 반응형(최소 폭 360px).

## 1. 라우트 맵

| 경로 | 화면 | 권한 |
|---|---|---|
| `/` | 시작 / 채팅 | 방문자 |
| `/admin/login` | 관리자 로그인 | 공개 |
| `/admin` | 대시보드 | 관리자 |
| `/admin/documents` | 문서 목록·업로드 | 관리자 |
| `/admin/documents/:id` | 문서 상세 | 관리자 |
| `/admin/chats` | 대화 세션 목록 | 관리자 |
| `/admin/chats/:sessionId` | 대화 상세 + 평가 요청 | 관리자 |
| `/admin/evaluations/:id` | 평가 결과 상세 | 관리자 |

## 2. 방문자 — 시작 화면

```text
┌──────────────────────────────────────────────┐
│  RAG Quality Lab · Java/Spring 기술 Q&A       │
├──────────────────────────────────────────────┤
│  등록된 문서를 근거로 답변하는 챗봇입니다.        │
│                                              │
│  ⚠ 안내                                       │
│  · 입력 내용은 저장되며(90일) 외부 AI 서비스      │
│    (Google Gemini)로 전송됩니다.               │
│  · 개인정보·회사 기밀을 입력하지 마세요.          │
│  · 대화를 종료하면 다시 볼 수 없습니다.           │
│                                              │
│            [ 대화 시작하기 ]                   │
└──────────────────────────────────────────────┘
```

## 3. 방문자 — 채팅 화면

```text
┌──────────────────────────────────────────────┐
│ RAG Quality Lab        남은 시간 29:12 [대화 종료] │
├──────────────────────────────────────────────┤
│ 🙋 @Transactional 기본 전파 속성은?              │
│                                              │
│ 🤖 기본 전파 속성은 REQUIRED입니다. 이미 진행 중인 │
│    트랜잭션이 있으면 참여하고 … [1]              │
│    ┌ 근거 ─────────────────────────────────┐ │
│    │ [1] 04_transaction.md › 전파 속성 ▾     │ │
│    │     "REQUIRED는 …" (펼치면 발췌 표시)    │ │
│    └──────────────────────────────────────┘ │
│                                              │
│ 🤖 ⓘ 등록된 문서에서 근거를 찾지 못했습니다.     │
│    질문을 바꾸거나 다른 주제를 물어봐 주세요.     │
├──────────────────────────────────────────────┤
│ [질문을 입력하세요 (최대 1,000자)      ] [전송] │
│ 0 / 1000                                      │
└──────────────────────────────────────────────┘
```
- 상태 표시: 전송 중 스피너, 오류 배너(예: "오늘 사용 가능한 요청을 모두 사용했습니다. 내일 다시 이용해 주세요." / "요청이 너무 잦습니다. 30초 후 다시 시도해 주세요.").
- 종료 클릭 시 확인 모달 "종료하면 이 대화를 다시 볼 수 없습니다." (브라우저 `confirm` 대신 자체 모달).
- 종료/만료 후: 입력창 비활성 + "새 대화 시작" 버튼.

## 7. 관리자 — 대화 목록 / 상세

```text
대화 세션   기간 [__ ~ __]  상태 [전체▾]  [검색]
│ 시작 시각 │ 상태 │ 질문 수 │ 평가 수 │ 마지막 활동 │
│ 11-12 10:00 │ 종료 │ 4 │ 1 │ 10:12 │ → 상세
```

```text
대화 상세 · 세션 0193…  상태: 종료(명시적) · 생성 10:00 · 종료 10:12
──────────────────────────────────────────────────────
🙋 Q1. @Transactional 기본 전파 속성은?
🤖 A1. 기본 전파 속성은 REQUIRED … [1]

   ▾ 검색 근거 (Top-5, 당시 스냅샷)
```

- [평가 요청] → 진행 상태 배지(대기/진행 중) → 완료 시 점수 표시.
