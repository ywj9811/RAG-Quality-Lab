# ADR-0001: 기술 스택과 버전

- 상태: 제안됨 (2026-11-12)
- 관련: 명세 2.1, CLAUDE.md 4절, `docs/phase0/02_compatibility_matrix.md`

## 배경
명세는 Java 21 / Spring Boot / Spring AI / React+TS / PostgreSQL+pgvector를 우선 검토하라고 한다. Spring AI의 현재 GA(2.0.2, 2026-10-23)는 Spring Boot 4.0.x/4.1.x만 지원한다.

## 결정 (제안)
- Java 21 (arm64), Spring Boot 4.1.x, Spring AI 2.0.2 (BOM), Gradle Wrapper 9.x(Kotlin DSL)
- PostgreSQL 17 + pgvector 0.8.7 (`pgvector/pgvector` 이미지, 버전 태그 고정), Flyway
- React + TypeScript + Vite, Vitest
- 테스트: JUnit 5, Testcontainers(pgvector 이미지)

## 대안
- Boot 3.5 + Spring AI 1.1.8: 자료는 많지만 구 라인. 신규 프로젝트에 이점이 적음.

## 결과
- 전역 Gradle 8.12.1은 Boot 4.1 요구(8.14+)에 미달 → Wrapper로 해결(전역 변경 없음).
- Spring AI 2.x 예제가 1.x보다 적을 수 있어 Phase 1 첫 작업으로 연동 스파이크를 둔다.
