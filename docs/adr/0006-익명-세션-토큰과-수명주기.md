# ADR-0006: 익명 채팅 세션 토큰과 수명주기

- 상태: 제안됨 (2026-11-12)
- 관련: CHAT-01, CHAT-02, CHAT-07, 명세 11절

## 결정 (제안)
- 세션 생성 시 256비트 난수 토큰 발급, DB에는 SHA-256 해시만 저장. 쿠키 `rql_chat`: `HttpOnly; SameSite=Strict; Path=/api/chat`, HTTPS 환경에서 `Secure`. Max-Age 없음(세션 쿠키).
- 모든 방문자 요청은 `{id}` + 쿠키 토큰 해시 일치를 확인. 불일치 → `404`(존재 비공개).
- 상태: `ACTIVE → CLOSED`(명시 종료, 즉시 무효) / `ACTIVE → EXPIRED`(유휴 30분 또는 생성 후 24시간; 요청 시 즉시 판정 + 5분 주기 일괄 갱신).
- 브라우저 이탈은 종료로 보지 않음(새로고침 유실 방지). 브라우저 종료 시 쿠키 소멸 + 서버 유휴 만료로 정리.
- 종료/만료 세션에 대한 조회·질문은 `410`. 관리자는 보관 기간 내 상태와 무관하게 조회.

## 대안
- `pagehide` + `sendBeacon` 자동 종료: 새로고침·탭 전환에서 오작동 → 비추천.
- JWT 무상태 토큰: 즉시 무효화를 위해 결국 서버 저장 필요 → 이점 없음.

## 결과
- 테스트 필수: 토큰 없음/불일치/종료 후/만료 후/다른 세션 ID 대입 시나리오.
