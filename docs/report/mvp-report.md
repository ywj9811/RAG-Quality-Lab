## 2. 검색 품질 (Phase 2, ADR-0003)

골든 질문 중 ANSWER 32개, Top-5, `qwen3-embedding:0.6b`: **Recall@5 0.938, MRR 0.833**. 놓친 2건은 복수 청크 질문. `./gradlew ollamaTest`로 재측정.

## 3. 생성 회귀 (골든 질문 40개, 실제 Gemini)

측정일 2026-11-19, `gemini-3.5-flash-lite`, 프롬프트 `gen-v1@0a4979bf`, 채팅과 같은 검색·임계값. `GenerationRegressionExternalTests` (수동, 생성 호출 39회).

| 지표 | 결과 |
|---|---|
| 기대 동작(ANSWER/REFUSE) 일치율 | **0.95** (38/40) |
| ANSWER 질문 중 인용을 포함해 답한 비율 | **0.938** (30/32) |
| 유형별 일치 | 정상 16/16, 표현 변경 8/8, 범위 밖 4/4, 근거 부족 4/4, 복수 청크 6/8 |
| 외부 오류 | 1건(시간 초과) |

불일치 2건은 모두 복수 청크 질문이다.
- `gq-04-04`(REQUIRED 안쪽 예외 + 감사 로그): 근거가 있는데 `[근거 부족]`으로 거절. 질문이 근거 3개를 요구해 모델이 보수적으로 판단한 것으로 보인다.
- `gq-06-04`: 생성 30초 시간 초과.

**범위 밖·근거 부족 질문 8개는 모두 지어내지 않고 거절했다.** 오거절 쪽 오류가 한 건 있으므로, 개선 시에는 복수 청크 질문을 위해 Top-K를 늘리거나 프롬프트 3번 규칙(부분 답변)을 강조하는 방향을 검토한다.

## 4. 보안 점검

| 항목 (명세 9절) | 결과 |
|---|---|
| 관리자 인증·인가 | 세션 쿠키(HttpOnly·SameSite=Strict), ROLE_ADMIN, 정의되지 않은 경로 거부, 세션 ID 교체 |
| 로그인 시도 제한 | 5회 실패 15분 잠금, 실패 응답 동일, 없는 계정도 해시 비교 |
| 익명 세션 소유권 | 256비트 토큰 해시 저장, 쿠키 Path=/api/chat, 불일치 404 |
| CSRF | 관리자·방문자 상태 변경 요청 모두 `X-XSRF-TOKEN` 필요(실제 HTTP 흐름 테스트) |
| 파일 검증·용량 | 확장자 + 내용 시그니처 + UTF-8, 10MB, UUID 저장명, 경로 문자 제거 |
| 프롬프트 인젝션 | 시스템 지시와 데이터 블록 분리, 태그 흉내 이스케이프, 도구 호출 없음, Judge 출력 서버 검증. 100% 방어는 불가(RK-03) |
| 출력 렌더링 | 답변·근거는 텍스트로만 표시(HTML·마크다운 미해석), CSP `default-src 'self'` |
| 개인정보 | 이메일·휴대전화·주민번호 형태 질문은 외부 전송 전 차단, IP는 솔트 해시만, 보관 90일 후 삭제 |
| 비밀값 | `.env`만 사용(커밋 안 됨), 커밋 전 비밀값 패턴 검사. API 로그에 질문 본문·쿠키·비밀번호 없음(확인일 로그 46줄 검사) |
| 노출 범위 | 모든 포트 127.0.0.1 바인딩, actuator는 health만 공개(나머지 401) |
| HTTPS | 로컬 전용이라 미적용. 공개 배포 시 `RQL_COOKIE_SECURE=true`와 HTTPS 필요(별도 승인 단계) |

## 5. 알려진 한계와 남은 과제

| 구분 | 내용 | 다음 조치 |
|---|---|---|
| Judge 가용성 | 11-19에는 503·시간 초과, 11-20에는 정상. 무료 RPD 20이라 재시도하지 않음 | 실패율이 높아지면 ADR-0004 변경 제안(예: 로컬 Ollama Judge) |
| Judge 편향 (RK-01) | 생성·Judge가 같은 Gemini 계열 | 사람 점수와 일치도 비교(오너 10~12건 수동 채점) — 오너 작업 |
| 골든셋 검토 | 40개 모두 DRAFT | 오너 검토 후 APPROVED |
| 근거 부족 판정 | 유사도 임계값만으로는 불가, 모델 판단에 의존 | 생성 회귀의 거절 일치율로 추적 |
| 복수 청크 질문 | 생성 회귀 불일치 2건 모두 복수 청크(오거절 1, 시간 초과 1) | Top-K·프롬프트 조정 후 재측정 |
| 분당 제한 | 인메모리라 재시작 시 초기화, 단일 인스턴스 전제 | 다중 인스턴스 시 재설계(ADR-0007) |
| 개인정보 탐지 | 흔한 형태만 | 필요 시 패턴 추가 |
| 공개 배포 | 범위 밖 | 약관(지역·연령), HTTPS, 남용 대책 검토 후 별도 단계 |
| 진단용 평가 1건 | Judge를 생성 모델로 임시 지정해 만든 100점 평가가 로컬 DB에 남아 대시보드 평균에 들어간다 | 오너가 원하면 삭제 |
